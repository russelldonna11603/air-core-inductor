## 三种公式各自什么时候准

| 公式 | 什么时候用 | 不要用的时候 |
| --- | --- | --- |
| Nagaoka 电流片 | 匝数够多、绕得比较密的单层空心线圈。页面上的主结果用它。系数按半径比 \(r/l\)，不是直径比。 | 一两匝。它把导线当成连续电流片，少匝会偏高，大约一成。 |
| Wheeler | \(l/D\) 大约在 0.4 以上的单层线圈，和 Nagaoka 很接近，方便手算。英寸公式 \(L(\mu\mathrm{H})=d^{2}N^{2}/(18d+40l)\)。 | 很短的线圈。\(l/D\) 小于 0.3 时它开始明显离开 Nagaoka。 |
| 圆导线回路 | 1 到 12 匝。单匝自感加同轴圆的互感（椭圆积分）。少匝以它为准。 | 匝数再多就不必了。电流片已经够用。 |

## 三种长度

同一个线圈，长度定义不同，电感就不同，因为长度直接进公式。

- 电流片：\(l = N \cdot p\)
- 中心距：\(l = (N-1) \cdot p\)
- 外包：\(l = (N-1) \cdot p + d\)

短线圈上，这个差别往往比 Nagaoka 和 Wheeler 的差别更大。

## 一组对照

\(N=3\)，绕径 \(D=2\,\mathrm{mm}\)，匝距 \(p=0.5\,\mathrm{mm}\)，电流片长度 \(1.5\,\mathrm{mm}\)，线径 \(0.4\,\mathrm{mm}\)：

- Nagaoka：14.89 nH
- Wheeler：14.76 nH
- 圆导线（含直流内感）：约 12.75 nH

少匝请用第三个数。

## 还算了什么，没算什么

算了：螺旋线长、铜直流电阻（\(1.68\times10^{-8}\,\Omega\cdot\mathrm{m}\)）、趋肤深度 \(\delta=65.23/\sqrt{f}\,\mathrm{mm}\)、交流电阻 \(\max(R_\mathrm{dc},\,R_\mathrm{dc}\cdot d/(4\delta))\)、Medhurst 密绕自电容（系数按厘米）、由此估计的自谐振、按目标电感反求匝数。

平面螺旋用 Mohan 1999（\(c_1=1,\,c_2=2.46,\,c_3=0,\,c_4=0.20\)）。磁环用厂家 \(A_L\cdot N^2\)，或 \(\mu_0\mu_r N^2 A_e/l_e\)。

没算：邻近效应、疏绕时的真实自电容、磁芯漏磁和气隙。这是绕线前的初值，不能代替测量或电磁仿真。
